# packages/legacy-sgq - Archived SGQ prototype

`legacy-sgq` preserves an early **Shifted-Grid Quantization (SGQ)** prototype.
It is frozen for archival reference and no longer maintained; the active
implementation lives in `packages/sgq`.

- Language: Python
- License: MIT
- Status: archived
- Implements: Shifted-Grid Quantization (SGQ)
- Benchmark (WQ-4 4-bit accuracy retention): 95.0

## Notes

This package is read-only. Reported figures are historical and the code is not
maintained.
